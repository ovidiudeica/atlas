# Surse și drepturi

Proveniența documentată separă instantaneele OSM Boundaries moderne, răspunsurile API OpenStreetMap, edițiile obiectelor din istoricul PBF, conturul ICR nedatat și referințele HURI pe epoci. © OpenStreetMap contributors. Drepturile și obligațiile OpenStreetMap se consultă în [licența datelor](https://www.openstreetmap.org/copyright). Arhiva atribuie separat sursele istorice și geometria ICR. Redistribuirea pachetelor private sau a surselor cartografice nu este atribuită de consolidare.
