# Proveniență și recuperare

Manifestul identifică PR-ul, commit-ul, calea și amprenta fiecărei versiuni. Copiile publice ale documentației pot înlocui locatorii privați cu trimiteri la această pagină. Originalele se recuperează byte-cu-byte din bundle. Pentru geometriile și tabelele originale, solicită acces la pachetele private proprietarului. Manifestul include calea exactă din ZIP și SHA-256-ul membrului.

Potrivirea între etape cere CRS identic și amprentă WKB identică într-o corespondență unică. Rândurile fără relație demonstrată rămân în HOLD. Această comparație nu înlocuiește amprenta fișierului original.
