# Surse și condiții de reutilizare

Seria folosește instantanee HURI, candidați OSM-Boundaries, conturul ICR, surse cartografice MSE, facsimile, referințe normative și inventare arhivistice. Pentru calificarea fiecărei surse folosește registrele etapei și PR-ul original indicat în manifest. O trimitere într-un inventar documentează pista de cercetare. Data publicării unei hărți și data conținutului administrativ sunt înregistrate separat.

Scanările, rasterele, fișierele GIS cu drepturi neclarificate și pachetele private rămân în custodia lor existentă. Autorizația de consolidare se aplică materialelor de cercetare proprii deja publicate și nu acordă drepturi suplimentare asupra surselor. Cere proprietarului accesul la copiile private pentru reproducere.
