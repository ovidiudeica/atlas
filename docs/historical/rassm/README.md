# RASSM Historical Evidence

**RESEARCH ONLY — DO NOT MERGE**

Indexul consolidează exclusiv cercetarea documentată în PR-urile #119–#128, publicate pe 17–18 noiembrie 2026. QGIS CURRENT desemnează instantaneul din acea serie. Rezultatele ulterioare și reconstrucția OSM #129–#134 se află în afara acestui perimetru.

Fișierele de cercetare își păstrează căile originale. Versiunile exacte și toate referințele originale sunt în bundle-ul local și în copia Drive privată. Unele rapoarte publice au doar locatorii privați eliminați. Manifestul leagă fiecare rezultat de PR, commit și obiectul Git.

Vezi [cronologia](RESEARCH-STATUS.md), [proveniența](PROVENANCE.md), [sursele](SOURCE-REGISTER.md) și [limitele și dependențele](HOLD-REGISTER.md).
