# HIST-RASSM.PROOF.2-C

PROOF.2a reconciles eight HURI snapshots, the undated ICR reference and all91 district candidates against the original OSM-Boundaries exports for Moldova(2026-10-05) andUkraine(2026-11-09).497 current administrative objects and41 historic/statistical context objects are examined separately.

The result contains32,722 temporal arc records. M1 admitted historical reuse and A/B certified length are bothzero. M2 and coincident M3 are geometric candidates requiring independent historical continuity evidence. The91 polygonized district candidates remainC; no canonical ACTUAL data or application code changes.

Read[RAPORT_FINAL.md](RAPORT_FINAL.md), which contains per-episode,per-sector and per-district tables. The compact complete arc register issegment_register.csv.gz, with hashes and the full private registry hash in segment_register_manifest.json. Full GeoPackages,GeoJSON,input data and the portable QGIS project are in the authorized[Drive11 package](https://drive.google.com/drive/folders/1N_EfIfYuJEHvbLiOuxtOmWbGi9w1KgY8).

Methods are inscripts/research/hist-rassm-proof-2. An independent empty-workspace run recomputes matching and noding without the first run's cache, then compares18 CSV files byte-for-byte and7 vector layers by WKB and attributes. Input hashes and software versions are published here. Raster scans and institutional HTML/PDF evidence remain in the private research package; source-specific rights limits are documented.

The new Dubasari grid test supports Bessel/Gauss-Kruger zone5 but does not establish a modern WGS84 datum transformation. Four new interior printed-grid holdouts are not physical ground controls. No point or boundary is admitted on that basis.
