# Reproduction and verification

Use the existing original research packages under outputs/11_HIST-RASSM_PROOF_2 through outputs/15_HIST-RASSM_PROOF_6 and the original undated ICR source under outputs/09_HIST-RASSM_FINAL/07_REPRODUCIBILITATE/inputs. SHA-256 inputs are pinned in SOURCE_VERSION.json. These are historical research dependencies for rebuilding; opening the delivered QGIS ZIP requires none of them.

Run Python with geopandas, pandas, shapely, pyogrio and pyproj. Place these scripts under work/qgis_current in the research workspace, or adjust the declared root paths before building. Run build_current.py, then qgis_current.py using the installed QGIS Python runtime. QGIS3.44.13 was used for verification. The Windows Arial registration fixes headless font discovery; the portable project stores only the font family, no font file dependency. Copy README.md to work/qgis_current and run bundle.py. The latter creates the clean six-file package and isolated_local extraction. Never publish SOURCE_VERSION.json or a manifest claiming a future readback: retain the actual verification records separately until the readback finishes.

Run gis_checks.py GPKG OUTPUT_JSON and reproduce.py with the normal geospatial Python. Run verify_portable.py EXTRACTED_FOLDER OUTPUT_JSON through QGIS Python in a separate process. The verifier rejects absolute or parent-directory datasource paths, resolves all36OGR layers to the extracted GPKG, reads every feature, tests default visibility/labels, validates SQLite and checks an actual rendered image. Use project.transformContext() for headless rendering of a reopened project. A no-error renderer alone is insufficient; non-background pixels and full extent are checked.

Upload only the six required files to the same permanent folder. Verify names, IDs and sizes using Drive API, download GPKG and ZIP, compare hashes, extract ZIP, rerun GIS/QGIS checks, and visually inspect the rendered map. DELIVERED_FILES.json and Drive_readback.json record the actual delivery. The inner manifest covers4contentfiles; the outer manifest additionally coversZIP, avoiding a circular hash.
